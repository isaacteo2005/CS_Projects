Spreadsheet_App
To run: Click on Test.sin and once in Visual Studios, run the application
* Spreadsheet application using winForms and C#
* allows adding text, numbers, background color
* undo/redo feature
* save/load
* practice for OOP principles and frontend coding

Subscription Manager
To run: follow the readme inside the project folder
* Application that helps track user subscriptions by entering subscription into a database
* Used supabase to store user and subscription data on the cloud and mySQL support to store data locally
* Registration/Login page and user page where users can add subscriptions and view statistics
* practice for using database and fullstack programming

Postscript_interpreter
* uses Lua to code an interpreter for PostScript
* practice for using a new language and creating a language interpreter
